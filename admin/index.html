🔒 Admin Security
The admin panel has no login by default — it relies on network access control.
Recommended: block /admin and /api/admin/* at your reverse proxy so only your local network can reach them.

Nginx example:
location ~ ^/(admin|api/admin) { allow 192.168.0.0/16; allow 10.0.0.0/8; deny all; }

Optional extra layer: set ADMIN_TOKEN=your-secret in docker-compose.yml under environment:. The admin UI will send it automatically once you set it here too:
